Cover images for the Home work grid go in this folder, at a 4:3 ratio:

  sensa.jpg
  flexpay.jpg
  goalden.jpg
  usability-performance-report.jpg

To use one, import it at the top of src/data/projects.js and set that
project's cover field to it, for example:

  import sensaCover from '../assets/covers/sensa.jpg'
  ...
  cover: sensaCover,
